# 🐾 开心消消乐 (Happy Match-3)

基于 **Cocos Creator 3.8 (TypeScript)** 开发的 Q 弹果冻糖果萌宠风格休闲三消手游。

---

## ✨ 核心特色

- **Q 弹果冻萌宠（纯代码高清矢量烘焙）**：
  - 启动时动态生成 $256 \times 256$ 视网膜超清纹理，无需外部美术资源，即开即用。
  - 角色：🐥 嘟嘟鸡、🐸 波波蛙、🐻 泡泡熊、🦊 小暖狐、🦉 梦梦猫头鹰、🌈 炫彩魔力鸟。
  - 迪士尼动画法则（Squash & Stretch）：落地受力挤压回弹，选中呼吸脉冲，泡泡破裂消除动效。
- **全套大师级特殊消除机制与高颜值视觉升级**：
  - **🚀 直线 4 消（横向/纵向火箭穿梭）**：告别单调箭头！搭载高科技流体力学火箭推进舱，双向立体晶体激光光棱箭头，喷射等离子流光尾焰，空气动力学破风流线与尖端钻石星芒，腰间镶嵌闪烁高能水晶核心，萌宠面容可爱不被遮挡。
  - **💣 L/T 型 5 消（爆裂熔岩能量护盾炸弹）**：8 瓣旋转烈焰能量波冲击圈、金光能量护盾、4 方位悬浮爆裂小晶球与右上角卷曲引火线噼啪迸发的金色火花。
  - **🌈 直线 5 消（七彩极光魔力鸟 / 梦幻星辰水晶球）**：七彩旋转极光光谱圆盘，左右舒展的金色天使萌羽小翅膀，深邃星空水晶球与月牙玻璃反光，中心立体八角璀璨金星与漂浮星屑。
  - 特效组合：双魔力鸟清屏、魔力鸟+条纹（全屏同色转条纹齐射）、双炸弹（5x5 大爆炸）、条纹+炸弹（巨型十字）。
- **纯程序合成音效系统 (Web Audio API)**：
  - 连击升调音阶、爆炸轰鸣、极光光效音、胜利通关赞歌，无需下载 MP3 即可清脆发声。
- **防死局机制**：
  - 棋盘无解时自动检测并重新洗牌（Shuffle）。

## 🛠️ 项目结构

```text
assets/
├── scene.scene          # 主场景
├── textures/            # AI 渲染生成的超清透明特殊图块贴图 (Rocket, Bomb, Rainbow)
└── scripts/
    ├── Types.ts         # 数据结构、枚举与基础配置
    ├── MatchLogic.ts    # 核心网格消除算法、特效合成与重力下落
    ├── ArtFactory.ts    # 动态 Canvas 2D 果冻萌宠与特效烘焙引擎
    ├── SpecialTileAssets.ts # 特效素材内嵌库与预加载管理器
    ├── TileItem.ts      # 单个图块视图组件及 Q 弹补间动画 (Tween)
    ├── TileRenderer.ts  # 矢量备用绘制组件
    ├── AudioService.ts  # Web Audio API 纯程序合成音效服务
    └── GameManager.ts   # 棋盘构建、输入手势监听与游戏主循环流水线
```

---

## 🚀 快速启动

1. 使用 **Cocos Creator 3.8.x LTS** 打开本项目。
2. 双击打开 `assets/scene.scene` 场景。
3. 点击编辑器顶部 **▶️ 运行预览**（推荐使用“浏览器”模式）即可畅玩。
