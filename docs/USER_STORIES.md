# 果园奇遇用户故事与验收标准

更新：2026-11-02。优先级：P0 必须完成核心关卡闭环；P1 构成可持续游玩的体验；P2 为后续扩展。每条故事用“作为玩家，我希望……，以便……”描述；验收条件可直接转为测试用例。迭代编号对应 [项目迭代计划](ITERATION_PLAN.md)。

## 核心操作与规则

### US-01 看懂关卡目标｜P0｜S2

作为第一次进入关卡的玩家，我希望开始前和对局中都能看到唯一的消除目标、血量和距下次受伤的行动数，以便知道该做什么、还能承受多少风险。

- 每关恰有一个主要目标，进入时显示目标图标、所需数量和当前进度。
- HUD 同时显示 HP 数值/血条和受伤倒计数；危险前 1 次行动有可辨识预警。
- 当目标变化时，HUD 在结算动画后更新；数字与实际棋盘事件一致。
- 暂停或重进关卡后，目标及进度不丢失。

### US-02 交换动物｜P0｜S1

作为玩家，我希望滑动或点选相邻动物完成交换，以便快速进行三消。

- 只接受相邻、可移动、未被藤蔓锁住的两个动物。
- 交换形成至少一组三连才记 1 次有效行动；无效交换回弹且不增加危险值。
- 动画和连锁期间的连续触摸不触发第二次交换。

### US-03 可预测的匹配与下落｜P0｜S1

作为玩家，我希望横向或纵向三个及以上同种动物被消除，并看到上方动物补位，以便理解每一步的结果。

- 横竖连续线按动物类型识别；彩鸟不参与普通同色匹配。
- 一个动物被多组匹配覆盖时只消除和计分一次。
- 下落后无空格、无重复引用和无越界；自然连锁继续结算，直到稳定。

### US-04 五连彩鸟落点正确｜P0｜S1

作为玩家，我希望彩鸟出现在我完成五连的位置，以便预测下一步操作。

- `22122` 中把中间 `1` 换成 `2` 后，五连彩鸟出现在左数第三格。
- 玩家交换形成的五连优先在参与匹配的交换落点生成；自然连锁五连取线中格。
- 横向与纵向五连都通过固定局面回归。

### US-05 四连方向动物｜P0｜S1/S3

作为玩家，我希望四连生成保留原动物身份的方向动物，以便知道它还能与哪种动物匹配。

- 水平四连生成横向状态，垂直四连生成纵向状态。
- 单个方向动物与任意普通动物交换不会直接触发；与同种动物形成三连后才扫行/列。
- 棋盘上的动物图、方向标识和实际消除方向一致。

### US-06 L/T 爆炸动物｜P0｜S1/S3

作为玩家，我希望 L/T 匹配生成同种爆炸动物，以便计划范围消除。

- L/T 交叉匹配优先于单独横线或竖线生成，交点只结算一次。
- 爆炸动物保持原动物类型；参与同种匹配后产生规定范围的命中。
- 边缘和角落爆炸不越界、不重复计分。

### US-07 特殊组合可理解｜P1｜S3

作为玩家，我希望两个特殊动物或彩鸟与动物交换时产生稳定的组合效果，以便提前规划。

- 为七类组合分别给出动画预告、受击范围和障碍交互规则。
- 相同固定局面与种子产生相同结果；连锁中的特殊动物至多触发一次。
- 组合结算后棋盘可继续操作，不发生半空格或卡住。

### US-08 死局与洗牌｜P0｜S1

作为玩家，我希望棋盘无合法移动时自动洗牌，以便不用放弃关卡。

- 判定只看交换后由被交换动物形成的匹配；棋盘上已有无关三连不算可行步。
- 洗牌后没有开局现成三连，且至少存在一步有效移动。
- 藤蔓锁住的动物不被洗牌移动。

## 障碍与关卡目标

### US-09 藤蔓只解除束缚｜P0｜S1

作为玩家，我希望被藤蔓困住的动物首次命中时保留下来，以便规则符合棋盘视觉。

- 藤蔓动物不可交换、不可因重力移动。
- 被同类匹配或特效命中时，藤蔓消失，原动物的类型、特殊状态和实体仍在。
- 同一回合连锁不会再次消除刚解开的动物；藤蔓奖励与普通动物奖励分别计分。

### US-10 冰块按层受击｜P0｜S3

作为玩家，我希望看见冰块每次受击减少一层，以便知道离目标还有多远。

- 每次有效命中只减少一层，层数和贴图同步。
- 冰块目标按实际清除计数；不会在没有冰块时重复发放清冰奖励。
- 与藤蔓同格时两种障碍的受击顺序由规则表定义并可测试。

### US-11 收集指定动物｜P1｜S3

作为玩家，我希望某些关卡要求消除指定种类动物，以便体验不同目标。

- 只有实际消失的目标动物增加计数；仅解除藤蔓不增加动物消除数。
- 特效范围消除和连锁消除都计入；重复覆盖只计一次。
- 达到本关唯一目标数量时进入胜利结算；同一行动即使达到受伤阈值也先胜利。

### US-12 收集物落底｜P1｜S5

作为玩家，我希望通过制造通道让收集物落到出口，以便获得不同于清除的策略。

- 关卡配置指定收集物、出口和生成位置。
- 收集物到出口时计数并播放反馈；特效对收集物的作用有明确规则。
- 出口被障碍阻挡、棋盘分段和同列多个收集物均有测试局面。

### US-13 血量归零与重试｜P0｜S2

作为玩家，我希望失败时知道差多少并能立即重试，以便继续挑战。

- 周期伤害结算后 HP 为 0 且目标未达成时，显示目标差额与重新开始入口。
- 重试恢复该关初始配置、满血和初始危险值，不保留上一局的障碍、护盾或目标进度。
- 同一行动的连锁达标先于伤害；护盾先于 HP 扣除；胜负只在棋盘稳定后判定。

## 新手体验、进度与反馈

### US-14 渐进教学｜P0｜S2/S3

作为新玩家，我希望在实际操作中逐步学会三连、特效和障碍规则，以便不用读长说明。

- 前 10 关逐项引入规则；首次出现新机制时给出一步可操作提示。
- 教学提示不挡住目标格；完成后消失，重进关卡可按需要重看。
- 教学局面可用固定种子复现，不依赖随机补位碰运气。

### US-15 选关与解锁｜P1｜S4

作为玩家，我希望从地图选择已解锁关卡，以便重玩和继续进度。

- 通关解锁下一关；未解锁关卡不能直接进入。
- 每关显示完成状态和最好星级；返回地图时位置保持。
- 无尽模式如继续保留，应作为独立入口，不覆盖主线进度。

### US-16 星级与结算｜P1｜S4

作为玩家，我希望结算展示目标、得分和星级，以便知道这一局的表现。

- 星级阈值由关卡配置决定，以受伤次数和完成目标的有效行动数为主，分数作为附加表现；相同过程结果一致。
- 重玩只更新更高星级，不降低历史记录。
- 结算数字与棋盘最终状态一致，不能在动画未完时提前结算。

### US-17 保存进度｜P1｜S4

作为玩家，我希望关闭游戏后继续上次进度，以便放心进行短局游戏。

- 已解锁关卡、最好星级、声音设置在重启后恢复。
- 存档版本升级有迁移或安全回退；坏档不会导致无法进入游戏。
- 存档写入失败可见但不阻断本局操作。

### US-18 清晰的因果反馈｜P1｜S5

作为玩家，我希望每次交换、命中、下落和达标都有对应的视觉与声音反馈，以便看懂连锁。

- 藤蔓断裂、冰块降层、动物消失、特殊扫线的时序与规则事件一致。
- 大连锁可加速，但最终目标进度、危险值和 HP 不能跳帧错算。
- 静音时无声音仍能通过视觉理解结果。

### US-19 触控与屏幕适配｜P1｜S5

作为手机玩家，我希望在常见竖屏尺寸上准确操作棋盘，以便长时间舒适游玩。

- 安全区、顶部目标和底部操作区不被刘海或系统手势遮挡。
- 拖动方向、点选交换和误触取消在至少两种屏幕比例上验证。
- 棋子最小触控区域与视觉位置一致。

### US-20 低运动与辨识度｜P2｜S6

作为对动画敏感或难区分颜色的玩家，我希望降低动画强度并靠形状辨认动物，以便正常游玩。

- 低运动模式缩短或关闭晃动、闪光与过强缩放，不改变结算结果。
- 五种动物及其特殊状态在灰度预览下仍可主要靠轮廓和标记辨认。
- 动效设置和静音设置可保存。

## 开发与关卡制作故事

### US-21 可复现 bug｜P0｜S1

作为开发者，我希望保存随机种子与操作序列，以便复现偶发的生成位置、连锁和死局问题。

- 给定相同关卡、种子和操作序列，最终棋盘、目标进度、危险值、HP 及事件序列一致。
- 错误报告可导出短文本，不含个人信息。

### US-22 配置与校验关卡｜P0｜S2

作为关卡设计者，我希望用版本化数据创建关卡并立即发现配置错误，以便稳定增加内容。

- 校验器检查格子范围、初始布局、单个目标、最大 HP、伤害间隔、障碍层数、规则 ID 和合法移动。
- 配置错误给出关卡 ID 与坐标；不让坏数据进入游戏。
- 旧配置升级时保持既有关卡结果可重放。

### US-23 调整难度｜P1｜S4/S5

作为关卡设计者，我希望看到每关的通过率、目标达成行动数、受伤次数与失败原因，以便调整血条压力。

- 测试数据按关卡版本区分；修改目标或布局后能比较前后结果。
- 仅在玩家知情的测试环境收集匿名统计；首版可先用本地导出。
- 关卡通过率不能单独决定质量，需结合试玩评论与目标理解情况。

### US-24 保持资源可扩展｜P1｜S5

作为开发者，我希望新增动物和状态图时无需手工把图片编码进 TypeScript，以便扩展内容。

- 图片作为 Cocos 资源加载，保留稳定资源键；缺图时明确报错或显示安全占位。
- 资源大小与首屏时间有可记录基线，迁移前后画质和引用一致。

## 长期系统候选（v1.x，独立排期）

### US-25 局前与局内辅助道具｜P2｜v1.x

作为玩家，我希望在卡关时使用有限的辅助道具，以便继续尝试自己的策略。

- 道具效果、可用时机和剩余数量在使用前可见；取消不消耗库存。
- 锤子、治疗/护盾和强制交换各有固定规则样例；藤蔓、冰块和特殊动物的交互不靠临时例外。
- 成功结算后才扣库存；同一次触摸和重试不能重复扣除。

### US-26 每日挑战｜P2｜v1.x

作为回访玩家，我希望每天有一局短挑战，以便获得不同于主线的目标。

- 每日挑战使用可版本化关卡配置，同一天同版本的规则与奖励一致。
- 离线与跨日时的进入、结算和重复领取边界有明确提示。
- 活动故障不影响主线关卡或本地进度。

### US-27 可选好友成绩｜P2｜v1.x

作为愿意与朋友交流的玩家，我希望自愿展示关卡成绩，以便分享通关经验。

- 默认不公开个人成绩；玩家主动启用后才展示。
- 排名来源、更新时间和同分规则可见；服务异常时仍能离线游玩。
- 退出或删除账号时，相关数据按产品设计处理并通过专项评审。

### US-28 跨设备继续｜P2｜v1.x

作为在不同设备游玩的玩家，我希望在登录后恢复进度，以便接着挑战。

- 登录前本地进度不会被空云档直接覆盖；冲突提供可理解的处理结果。
- 同步失败时保留本地可玩状态，恢复连接后可重试。
- 服务端存档与客户端规则版本不兼容时阻止错误覆盖。

### US-29 预判周期受伤｜P0｜S1/S2

作为玩家，我希望每次有效行动后看见距受伤还有几次行动，以便在血量下降前规划消除。

- 默认 5 HP、每 4 次有效行动受 1 点伤害：前三次行动不掉血；第四次未完成目标才掉血。
- 非法交换、自动洗牌、连锁和动画不增加危险值；同一行动最多触发一次周期伤害。
- 若第四次行动完成目标，先胜利不受伤；护盾先吸收伤害，治疗不超过最大 HP。

### US-30 理解关卡规则变体｜P1｜S3/S5

作为玩家，我希望进入关卡前就知道本关如何改变受伤节奏或防护方式，以便选择策略。

- 每关只有一个主要目标，另可选择至多两种兼容的规则变体。
- 规则卡展示触发条件、数值和上限；触发时 HUD 给出来源提示。
- 不兼容组合在关卡校验时拒绝；同一配置与种子可复现。

### US-31 选择并理解遗物｜P2｜v1.x

作为希望构筑玩法的玩家，我希望获得少量有明确触发条件的遗物，以便形成自己的过关策略。

- 遗物显示触发时机、剩余次数、冷却与叠加上限，触发记录可查看。
- 与关卡规则共享治疗、护盾、危险值等原子效果，但不改变本关唯一目标。
- 多个遗物按固定顺序结算；同一事件不能重复触发，且不会形成无限循环或永久无敌。

## 首版范围说明

P0/P1 形成 v1.0 单机主线。P2 遗物获取与构筑在主线稳定后单独评估；付费、体力、周赛和大型活动暂不预设交付日期。当前先验证单目标、血条压力、规则游玩集与可扩展的内容管线。参考体验依据与架构见 [技术路线图](TECHNICAL_ROADMAP.md)和[规则游玩集](GAMEPLAY_RULESET.md)。
